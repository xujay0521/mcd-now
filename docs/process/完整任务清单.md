# 趁热麦 McNow 完整任务清单

## 状态约定

- `[x]`：已完成并验证。
- `[~]`：正在处理。
- `[ ]`：尚未开始。
- `[!]`：需要用户授权或真实业务环境确认。

## 首版验收场景

1. 用户明确说“以后优先鸡肉汉堡，不要饮料”，Skill 保存并可修改该偏好。
2. 用户没有券时，Skill 查询可领取券并提醒，不擅自领取。
3. 用户有临期券时，Skill 说明到期时间，并验证当前或附近门店能否核销。
4. 当前门店不可用时，仅把最近已验证可用门店作为补救建议，并给出粗略 ETA。
5. Skill 根据实时菜单、券和偏好生成到店自取建议，以 MCP 核价结果为准。
6. 用户明确确认当前订单草稿后，Skill 二次核价，无变化才创建到店自取订单。
7. CLI 可被计划任务调用，但只读取用户主动导出的本地脱敏券快照；无新提醒时静默，不连接 MCP，也不执行领券或下单。
